Tools of the Trade

Web programs and web pages are created and modified with a text editor but are viewed - or run - in a browser. To create and modify our web programs, we'll use a popular IDE - VSCode. VSCode has features for many programming languages.

Web pages are created and edited in a text editor and viewed in a browser.
download vscode

If you do not already have VSCode installed, download it now.

VSCode

View this Getting started with Visual Studio Code video for an introduction to working in VSCode.

VSCode Extensions​

VSCode uses plugins - known as extensions in VSCode - for specific language features. The library of extensions is vast and includes some that are useful when editing html files.

Live Server VSCode extension

I recommend installing the Live Server extension from the marketplace. This extension allows you to edit files in VSCode and view them in a browser without leaving VSCode.

Install the Live Server extension to VSCode
