Arrays

  • JavaScript arrays can hold values of mixed types.
  • The size of an array is dynamic and auto-growing.
  • You don’t need to specify the array size up front.
  • Arrays can be constructed with either the new keyword with the Array() constructor, or with array literal notation - [ ]- - square brackets
  • length returns the size of the array
// create an empty array
let scores = new Array();
let artists = Array();
let emptyArray = [];

// if you know the number of elements
// create a scores array for 10 elements
let scores = Array(10);

// create and initialize an array
let scores = new Array(9,10,8,7,6);
let colors = ['red', 'green', 'blue'];

// length returns the size of the array
console.log(colors.length);// 3


  • Arrays dynamically add elements to the end of an array with
myarray.push('new item');
  • remove an item from the end of an array with:
lastitem - myarray.pop();
  • find the index of an element with the indexOf() method
  • check if a value is an array with the isArray() method:
let teams = ['Falcons', 'Saints', 'Panthers'];
teams.push('Jaguars');

const lastElement = teams.pop(); console.log(lastElement); // Jaguars

// find the index with indexof
let index = teams.indexOf('Panthers'); console.log(index);// 2

// to check if teams is an array
console.log(Array.isArray(teams));// true

Destructuring​

Array destructuring provides a convenient way to extract elements from an array or properties from objects in a single line of code.

Destructuring provides short, clean syntax to unpack:

  • values from an array
  • properties from objects to distinct variables.
const league = ["Steelers", "Falcons", "Patriots", "Browns"];

// one way to extract
let team1 = league[0];
let team2 = league[1];

// with array destructuring
let [team1, team2] = league;

Spread​

The JavaScript spread operator (...) allows us to quickly copy all or part of an existing array or object into another array or object. The spread allows an iterable to be expanded in places where zero or more arguments (for function calls) or elements (for array literals) are expected, or an object expression to be expanded in places where zero or more key-value pairs (for object literals) are expected.

The three dots "spread" the array so that its elements become elements within the array literal that is being created.

// spread with arrays
const numbersOne = [1, 2, 3];
const numbersTwo = [4, 5, 6];
const numbersCombined = [...numbersOne, ...numbersTwo];
// It's as if the …a is replaced 
// by the elements of the array a.

let a = [1, 2, 3];
let b = [0, …a, 4]; // b == [0,1,2,3,4]

for/of​

for/of is a new addition to JavaScript

  • runs once for each element
  • works with iterable objects:
    • arrays,
    • strings,
    • sets, and
    • maps
for ( variable of iterable_object) {
    body 
}
// functionally equivalent
for (let i = 0; i < years.length; i++) {
     let yr = years[i];
     console.log(yr);
}
// iterating through an array
for (let yr of years) {
     console.log(yr);
}
// iterating through a string
const iterable = "boo";

for (const value of iterable) {
  console.log(value);
}
// "b"
// "o"
// "o"

Array methods​

ForEach​

ForEach: iterates through an array invoking a function you specify for each element. You pass the function as the first argument and forEach() then invokes your function with (optionally) three arguments:

  • the value of the array element,
  • the index of the array element
  • the array itself If you only care about the value of the array element, you can write a function with only one parameter - the additional arguments will be ignored:
let data = [1,2,3,4,5], sum = 0;
// compute the sum of the elements
let sum = 0;
data.forEach(value => {sum += value;});
// sum == 15

// Now increment each array element
data.forEach((v, i, a) => a[i] = v + 1);

// data == [2,3,4,5,6]

numbers = [1,2,3,4,5];
function print(element) {
   console.log(element)
}
numbers.forEach(print);

Map​

Map: passes each element of the array on which it is invoked to the function you specify and returns a new array of the same size containing the values returned by your function.

The function you pass to map() is invoked in the same way as a function passed to forEach(). For the map() method, however, the function you pass should return a value.

map() returns a new array.

const numbers = [1,2,3,4,5];

// map
numbers.map(function (num) {
   return num * 2;
})
// => [2,4,6,8,10];

// map
numbers.map( x => x*x )  
// => [1,4,9,16,25];

Filter​

Filter: creates a new array with all elements that pass the test implemented by the provided function. filter() returns a subset of the elements of the array.

The function passed should return true or false.

find() and findIndex() look for elements in an array like filter but find() and findIndex() return the matching element or index and stop iterating.

const numbers = [1,2,3,4,5];
// filter
numbers.filter(function (num) {
   return num < 3;
})
// filter even numbers
numbers.filter(n => { n%2 === 0;})

// find
numbers.find(x => x%5 === 0) // => 5
numbers.find(x => x%7 === 0) // => undefined

// findIndex
numbers.findIndex(x => x === 3) 
// => 2 since value 3 is at index 2

sort​

sort: sorts the elements of an array in place and returns the sorted array.
When called with no parameters, sort() sorts the elements in alphabetical order.

To sort an array into some order other than alphabetical, you may pass a comparator function. The function determines the order of the elements. It takes two arguments, often referred to as a and b, and returns:

  • A negative value if a should come before b
  • Zero if a and b are considered equal (keeps original order)
  • A positive value if a should come after b
let a = [33, 4, 1111, 222];

a.sort();	// alphabetical order
		// [1111, 222, 33, 4];

a.sort(function(a,b) { // comparator fn			return a-b;	// Returns <0, 0, or >0
});				// [4, 33, 222, 1111]
				// numerical order

a.sort((a,b) => b-a); // reverse order
// [1111, 222, 33, 4]

reduce​

Reduce: combines the elements of an array, using the function you specify, to produce a single value. reduce() takes two arguments: the function that performs the reduction operation and the second (optional) argument is an initial value to pass to the function.

The task of the function is to combine or reduce two values to a single value and return the reduced value.

every() and some() apply a predicate function you specify to the elements of the array, then return true or false.

const numbers = [1,2,3,4,5];
// reduce
numbers.reduce((x,y) => x+y, 0) // 15

numbers.reduce((x,y) => x*y, 1) // 120

// true iff function returns true for all 
// elements in the array.
numbers.every(x=> x < 10) // true

// true if at least one element in the array // returns true
numbers.some(x => x%2 ===0) // true since
// numbers has some even numbers
