Authorization with NextAuth

Authorization is the process of verifying what the user is allowed to do. In this tutorial, we'll implement authorization with JSON web tokens - JWTs. We'll use the user information in the token to conditionally render a navbar.

This tutorial begins where the 'Credential login with NextAuth' tutorial ended. The auth setup, signup and login forms should be complete so that JWT sessions are enabled. Now we will use the session token to allow only authenticated users to add (create-item), edit (update-item) and delete (delete-items) items.

Session Management​

auth() provides access to the session data in server components. To access the session data in client components, we can use the useSession() hook. The signOut() invalidates the session and deletes the JWT cookie.

Middleware​

Middleware is code that executes between a client's request and the server's response. Middleware can be used to process requests and is executed before the request is completed. We'll use middleware to 'protect routes' so that only an authenticated user can reach a certain route. Middleware can access session data.

If a request is authorized, we call next() to continue to the server endpoint. If not authorized, return with a 403 status and/or redirect to another route.

Middleware setup​

In a Nextjs application, we set up middleware by creating a file called middleware.ts at the project root and including a middleware() function.

We can implement authorization and protecting routes with middleware. The middleware function can check if the user is authenticated before the request is forwarded to the server endpoint.

middleware.ts
const middleware = async (request: NextRequest) => {
    const { pathname } = request.nextUrl;
    const session = await auth();
    const isAuthenticated = !!session?.user;

    const publicPaths = ["/", "/show-item", "/show-items", "/api/items"];

    if (!isAuthenticated && !publicPaths.includes(pathname)) {
        return NextResponse.redirect(new URL("/", request.url));
    }

    return NextResponse.next();
 
};

export const config = {
  matcher: [
    "/create-item/:path*",
    "/update-item/:path*",
    "/delete-item/:path*",
  ],
};

The middleware ensures that only authenticated users can reach certain reoutes.
If the user isn't logged in, they are redirected to the login page. Here's a breakdown:

  1. auth() is provided by NextAuth to provide access the current user session user data. On a match with this middleware, auth() is is called before the endpoint.
  2. const isAuthenticated = !!req.auth?.user; : If a valid session exists, session.user contains the user object. !! converts it to a boolean value. (If user - true)
  3. if the user isn't logged in, redirects them to /login.
  4. return NextResponse.next(); : continue processing the request - allow to proceed on the route.

Matcher​

In Next.js, the matcher in the middleware function controls which routes the middleware will be applied to. It acts as a filter, ensuring that the middleware only executes for specific paths or patterns. This allows for targeted middleware behavior, such as authentication checks for certain routes or API requests.

Session data​

auth()​

auth() is provided by NextAuth to provide access to the current user session user data. We use auth() in middleware() to get access to the user info. You can also check the session in route handlers and server components to see if the user is authenticated.

useSession()​

In Next.js with Auth.js, the useSession() hook in client components returns an object. The object returned by auth() contains session data and details about the authenticated user. user: An object containing information about the user if the user is authenticated. If the session is still loading, it will be undefined. If the session fetch failed or the user is not authenticated, it will be null.

user from auth​

We want to render a personalized welcome message to a user who is authenticated. We can access the user data in the session returned from auth():

components/Navbar.tsx
export default async function Navbar() {
  const session = await auth();
  const isLoggedIn = !!session?.user;

  return (
    <nav className="navbar">

        ...
        {isLoggedIn ? (
            <>
              <Link href="#">
                Welcome {session.user.name}
              </Link>
                
              <LogoutButton />
            </>
        ) : (
            <Link href="/login">
                Login
            </Link>
        )}
        ...
    </nav>
